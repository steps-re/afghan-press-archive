Design studies

The same archive rendered several ways. Each one is a working interface over the live collection rather than a mock-up: search it, open a page, page through the scan, switch the interface to Persian. Nothing here is filler text.

01
Swiss / International
Grid discipline, one accent, nothing decorative. The Müller-Brockmann answer: information as the only ornament.
02
Modern Afghan
Lapis, madder and gold — the pigments of Herat illumination — driving a contemporary layout. Geometry from tilework, not from a CSS framework.
03
Illuminated manuscript
Ruled margins, gold leaf, a sarlawh over the title. The page treated as a codex opening rather than a screen.
04
Constructivist
1920s again — diagonals, primary blocks, type as structural element. The visual language contemporary with the later half of this archive.
05
Synthesis — warm
The same spine turned toward the manuscript: paper ground, ruled gold frame, a khatam headpiece — still on a strict grid, with constructivist weight in the rules.
